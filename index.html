Usa tu propia clave de Gemini. La clave solo se conserva durante esta sesión del navegador.

¿Cómo obtener mi clave API de Gemini?

La clave se obtiene directamente en Google AI Studio. Necesitas iniciar sesión con una cuenta de Google.

  1. Abre la página oficial de claves de Google AI Studio.
  2. Inicia sesión con tu cuenta de Google.
  3. Crea una nueva clave o copia una clave existente de Gemini API.
  4. Regresa a esta aplicación, pega la clave en API Key de Gemini y pulsa Guardar para esta sesión.
Ir a Google AI Studio Guía oficial de Google

La disponibilidad, cuotas y posibles cargos dependen de tu proyecto y de las condiciones vigentes de Google.

Privacidad de Gemini: el documento se envía directamente a la API de Google usando tu clave. El uso y retención dependen del tipo de servicio/cuenta de Gemini. Evita enviar información personal o confidencial si utilizas cuota no pagada.
