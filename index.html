¿Cómo obtener la API y qué modelo elegir?

🛠️ Pasos para obtener tu API Key

  1. Ingresa a Google AI Studio e inicia sesión con Google.
  2. Haz clic en el botón "Get API key" o "Create API key".
  3. Selecciona "Create API key in new project".
  4. Copia la clave generada (suele empezar con AIza...) y pégala arriba.

🤖 Modelos: ¿Gratis o de pago?

¡Todos son gratuitos en AI Studio! Google ofrece una "Capa Gratuita" muy generosa para desarrolladores. No te cobrarán a menos que vincules una tarjeta de crédito en la consola de Google Cloud.

  • Modelos Flash: Son rapidísimos y excelentes para leer documentos largos. Tienen un límite gratuito alto (hasta 15 peticiones por minuto). Recomendados para esta app.
  • Modelos Pro: Tienen mayor capacidad de razonamiento complejo, pero son un poco más lentos y el límite gratuito es más estricto (solo 2 peticiones por minuto).
